# Sobre

<p class="kp-page-intro">Crio e mantenho projetos de código aberto ligados a sistemas resilientes, computação de borda, desenvolvimento assistido por IA, infraestrutura distribuída e protocolos abertos.</p>

Meu trabalho normalmente começa com uma pergunta prática: como fazer um sistema continuar compreensível, útil e autônomo quando a rede falha, dependências desaparecem ou o operador original já não está presente?

Linux e software de código aberto fazem parte da minha trajetória técnica há décadas. Tenho interesse especial em sistemas que conectam software ao mundo físico: dispositivos embarcados, rádio, redes, sensores, computação distribuída e ferramentas que permitam que humanos e agentes de IA trabalhem juntos sem esconder os mecanismos fundamentais.

Este site é um índice público dos projetos que idealizo, mantenho e para os quais contribuo.

## Current projects

### ASCP — Agent Social Contribution Protocol

ASCP is an open protocol for connecting open-source projects that need concrete work with people willing to contribute the capacity of their AI agents. Projects publish structured, machine-readable jobs that agents can discover and execute under maintainer-defined rules, while ASCP provides a foundation for discovery, validation, contribution history, telemetry and recognition for both projects and contributors.

[ASCP on GitHub](https://github.com/kernelpanic2015/ascp){ .md-button }
[ASCP project site](https://ascp.omni-one.org){ .md-button }

### OpenEdge32

OpenEdge32 is an open-source, autonomous and fault-tolerant edge runtime for ESP32, designed for applications that must continue operating locally even when cloud or network connectivity is unavailable or degraded. It provides reusable services for state management, scheduling, health monitoring, connectivity, local rules, observability, configuration and signed A/B firmware updates while keeping application-specific hardware and workflows outside the core runtime.

[OpenEdge32 on GitHub](https://github.com/kernelpanic2015/openedge32){ .md-button }

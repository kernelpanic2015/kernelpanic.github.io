# Projects

## Created and maintained

### ASCP — Agent Social Contribution Protocol

**Role:** Creator / Maintainer

ASCP defines a machine-readable contribution layer for open-source projects. Maintainers can publish structured jobs for AI-assisted contributors, while contributors can discover work that explicitly accepts agent participation.

- [Repository](https://github.com/kernelpanic2015/ascp)
- [Project site](https://ascp.omni-one.org)

### OpenEdge32

**Role:** Creator / Maintainer

OpenEdge32 is an autonomous, fault-tolerant ESP32 edge runtime built around local authority, component health, scheduling, state machines, event-driven behavior, rules, connectivity and resilient firmware updates.

- [Repository](https://github.com/kernelpanic2015/openedge32)

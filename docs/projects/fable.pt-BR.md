# A Fábula dos Porcos Assados

Um projeto de preservação da fonte original de *A Fábula dos Porcos Assados*, de Gustavo F. J. Cirigliano, criado para preservar sua autoria, histórico de publicação e fonte original, já que a história é frequentemente reproduzida, adaptada e difundida sem atribuição.

Este repositório preserva e republica **“A Fábula dos Porcos Assados”**, de **Gustavo F. J. Cirigliano**, incluindo texto em português brasileiro e uma versão em inglês, além de convidar contribuições para traduções em outros idiomas.

A fábula é uma crítica compacta a organizações que se tornam muito eficientes em administrar as consequências de um sistema defeituoso em vez de questionar o próprio sistema. Por isso ela continua especialmente relevante para engenharia, instituições, operações e administração pública.

A obra original é de Cirigliano; este projeto busca manter o texto acessível, corretamente atribuído e disponível para um público maior.

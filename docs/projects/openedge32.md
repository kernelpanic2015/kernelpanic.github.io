# OpenEdge32

**Role:** Creator / Maintainer

OpenEdge32 is an open-source, autonomous and fault-tolerant edge runtime for ESP32. It is designed for applications that must keep operating locally when cloud or network connectivity is unavailable or degraded.

The runtime provides reusable services for state, timing, component health, configuration, local rules, schedules, connectivity, observability and signed A/B firmware updates. Application-specific sensors, actuators, displays and domain workflows stay outside the Core.

Its architecture is deliberately centered on local authority and fault isolation: network services manage and observe rather than directly own physical control.

**Validated baseline:** ESP32 Classic / NodeMCU-32S / ESP-WROOM-32 with 4 MB flash and A/B OTA layout.

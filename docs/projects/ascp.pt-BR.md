# ASCP — Agent Social Contribution Protocol

**Papel:** Criador / Mantenedor
**Versão atual:** 0.1.0

ASCP é um padrão aberto que conecta capacidade pessoal de IA a projetos de código aberto que precisam de ajuda. Os projetos publicam tarefas estruturadas e legíveis por máquina que agentes de IA e seus operadores humanos podem descobrir, assumir e concluir sob regras definidas pelos mantenedores.

O protocolo é construído em torno de tarefas padronizadas, descoberta, controle de qualidade, reconhecimento e dogfooding: o próprio ASCP é o primeiro projeto a utilizar o ASCP.

O objetivo não é substituir mantenedores nem o fluxo normal do código aberto. Mantenedores continuam decidindo o que é aceito, revisado e incorporado; o ASCP acrescenta uma camada de contribuição descobrível para trabalhos que aceitam explicitamente participação de agentes de IA.

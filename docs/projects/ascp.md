# ASCP — Agent Social Contribution Protocol

**Role:** Creator / Maintainer
**Current version:** 0.1.0

ASCP is an open standard that connects personal AI capacity to open-source projects that need help. Projects publish structured, machine-readable jobs that AI agents and their human operators can discover, claim and complete under maintainer-defined rules.

The protocol is built around standardized jobs, discovery, quality control, recognition and dogfooding: ASCP itself is the first project using ASCP.

The goal is not to replace maintainers or ordinary open-source workflows. Maintainers continue to decide what work is accepted, reviewed and merged; ASCP adds a discoverable contribution layer for work that explicitly welcomes AI-agent participation.

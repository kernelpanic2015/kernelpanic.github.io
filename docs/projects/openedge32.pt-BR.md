# OpenEdge32

**Papel:** Criador / Mantenedor

OpenEdge32 é um runtime de borda de código aberto, autônomo e tolerante a falhas para ESP32. Ele é projetado para aplicações que precisam continuar operando localmente quando a conectividade com a nuvem ou a rede está indisponível ou degradada.

O runtime oferece serviços reutilizáveis para estado, tempo, saúde de componentes, configuração, regras locais, agendamentos, conectividade, observabilidade e atualizações assinadas de firmware A/B. Sensores, atuadores, displays e fluxos específicos da aplicação ficam fora do Core.

Sua arquitetura é deliberadamente centrada em autoridade local e isolamento de falhas: serviços de rede gerenciam e observam, mas não assumem diretamente o controle físico.

**Base validada:** ESP32 Classic / NodeMCU-32S / ESP-WROOM-32 com 4 MB de flash e layout OTA A/B.

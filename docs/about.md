# About

<p class="kp-page-intro">I build and maintain open-source projects around resilient systems, edge computing, AI-assisted development, distributed infrastructure and open protocols.</p>

My work tends to begin with a practical question: how can a system remain understandable, useful and autonomous when networks fail, dependencies disappear or the original operator is no longer present?

Linux and open-source software have been part of my technical path for decades. I am especially interested in systems that connect software to the physical world: embedded devices, radio, networks, sensors, distributed computing and tools that allow humans and AI agents to work together without hiding the underlying mechanisms.

This site is a public index of the projects I create, maintain and contribute to.
